# RoEmotion 1.0 — September 16th 2026

Options now starts with **Change Emotion Detection Model**. The existing
ResNet-50 + LSTM + Attention Model remains available under **Previous Models**
and remains the default for existing installations.

**Current Models** contains **Trained with Random Distribution** and
**Trained with Different Person Validation**. Each provides Standalone
ResNet-50, ResNet-50 + LSTM, and ResNet-50 + LSTM + Attention, followed by a
choice of Raw or Kalman Filter + CV. All twelve current models and the previous
model are bundled for offline inference. Choosing a current model selects its
matching trace processing automatically.

Current models use their original nine-class ordering, black-letterboxed input,
and trained weights. Standalone models use one frame; recurrent models accept
one to five real frames, with five collected during live inference. Current
tracking history resets after gaps longer than ten seconds. Switching models
clears previous predictions and reloads inference without restarting the app.
See [export documentation](../../scripts/README.md) for source provenance,
checksums, and reproducible conversion.

About Us lists Deniz Acikbas, Hasky Fynn, Thuy-Anh Nguyen, Amina Bilal, and
Christian Nwobu, with the release date September 16th 2026.

Dark mode uses light blue dialog text, choices, buttons, and input fields on a
dark blue background. The model picker and standard Options dialogs follow the
system theme; light mode retains its existing appearance.
